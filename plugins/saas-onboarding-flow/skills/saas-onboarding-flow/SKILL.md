# SaaS Onboarding Flow

## When to Use This Skill

- The user wants to improve activation or early retention.
- A product needs welcome emails, onboarding steps, checklists, tooltips, or demo data.
- The first users need manual onboarding scripts.

## When Not to Use This Skill

- The product has not been validated and there are no users.
- The user only needs marketing acquisition copy.

## Intake Questions

Ask only for missing information that changes the output. If enough context exists, proceed and state assumptions.

- What is the activation event or first-value moment?
- What does the user know before signup and what do they need to do next?
- Should onboarding be self-serve, concierge, sales-led, or hybrid?

## Operating Workflow

- Start with the shortest path from signup to first value.
- Ask only questions needed to personalize the path.
- Use a 3 to 5 step checklist mapped directly to activation.
- Send the first welcome email within 60 seconds with one next action.
- For first 10 to 20 users, prioritize manual onboarding to learn friction.
- Create lifecycle messages for day 1, day 3, day 7, day 14, and day 30.

## Output Contract

Always produce practical artifacts the user can copy, paste, configure, or hand to a contractor.

- Onboarding flow map.
- Checklist tasks.
- Welcome and lifecycle emails.
- Empty-state copy.
- Manual onboarding call script.

## Quality Checklist

Before finalizing, verify:

- No onboarding step exists just to teach a feature; each moves toward value.
- The user always knows what to do next.
- The flow captures segmentation without creating friction.

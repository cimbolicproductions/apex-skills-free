# AEO and GEO

Extract this ZIP into a directory named `aeo-and-geo`. Keep all subdirectories together. Read `SKILL.md` and `_shared/execution-standard.md`. Python 3 runs `python scripts/audit.py <URL-or-local-HTML-path>` without extra dependencies.

The `related-skills/` directories contain public companion workflows. Read them directly when the main skill calls for them; you can also install each as its own skill using its directory name. Public files omit private operational evidence and personal account details. This is an extractability workflow with measurement, not a promise of AI citations or leads.

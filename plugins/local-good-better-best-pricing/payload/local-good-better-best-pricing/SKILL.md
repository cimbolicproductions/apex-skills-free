# Good-Better-Best Local Pricing

## When to Use This Skill

- The user only offers one price and wants packages.
- The business wants higher average ticket, clearer choices, or less price haggling.
- The user needs tier names, inclusions, price gaps, and presentation script.

## When Not to Use This Skill

- The business is legally required to use fixed regulated pricing.
- The user only needs SaaS subscription pricing.

## Intake Questions

Ask only for missing information that changes the output. If enough context exists, proceed and state assumptions.

- Service type, baseline price, cost drivers, warranty options, speed options, add-ons, and capacity.
- Which tier should most customers choose?
- What premium outcome can justify the Best tier?

## Operating Workflow

- Define Good as minimum viable solution.
- Define Better as the recommended value tier with warranty, convenience, protection, or speed.
- Define Best as premium anchor with concierge service, extended warranty, priority scheduling, or bundled annual care.
- Use price gaps around 15 to 25 percent from Good to Better and 35 to 55 percent from Good to Best unless economics dictate otherwise.
- Create a visual comparison that makes Better the obvious choice.
- Write the sales script to present options neutrally but recommend Better.

## Output Contract

Always produce practical artifacts the user can copy, paste, configure, or hand to a contractor.

- Three-tier pricing table.
- Included/excluded scope language.
- Upsell and downsell script.
- Quote menu copy.
- Objection responses.

## Quality Checklist

Before finalizing, verify:

- Each tier is profitable.
- Differences are tangible, not fluff.
- The salesperson can explain the recommendation in one sentence.

# Personal Context Vault Skills Pack

This pack helps Claude create and maintain a deeply organized local context vault for a user.
It is designed for people who use AI heavily and need a durable source of truth for personal context,
projects, goals, blockers, decisions, brain dumps, workflows, and AI handoffs.

The skills are intentionally granular so Claude can auto-load the right procedure from natural language:

- **context-vault-architect**: Create the folder structure, templates, naming rules, and index files.
- **guided-brain-dump-capture**: Interview the user and turn messy thoughts into organized notes.
- **project-context-captain**: Build project pages with goals, status, constraints, decisions, tasks, and next actions.
- **blocker-snag-triage**: Capture where the user is stuck and convert blockers into action paths.
- **weekly-context-review**: Run a weekly review that cleans, promotes, archives, and reprioritizes context.
- **ai-handoff-brief-builder**: Generate Claude/ChatGPT/Claude Code ready context briefs from vault notes.
- **personal-operating-system-map**: Build a full map of roles, businesses, tools, routines, assets, responsibilities, and recurring workflows.
- **vault-ingestion-router**: Decide where any new note, transcript, screenshot, meeting, idea, or link belongs.

The included bootstrap script creates a local folder tree and starter templates.

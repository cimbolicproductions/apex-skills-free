# Marketplace Photo Coach

## When to Use This Skill

- The user needs a photo shot list for a listing.
- Photos are dark, cluttered, incomplete, misleading, or missing flaw details.
- The item is large, used, high-value, or condition-sensitive.

## When Not to Use This Skill

- The user asks for AI-generated product images for a real used item; real photos are required.
- The item cannot be safely moved or photographed without risk.

## Intake Questions

Ask only for missing information that changes the output. If enough context exists, proceed and state assumptions.

- Platform, item type, condition, flaws, and available location/lighting.
- What questions would a buyer ask before driving or paying?
- Does the item need scale, serial/model label, power-on proof, or test proof?

## Operating Workflow

- Clean the item and remove clutter before shooting.
- Use natural or even lighting, no harsh flash, and a plain background.
- Shoot front, back, sides, top, close-ups, labels, accessories, flaws, and in-use/test proof.
- For eBay, meet minimum image quality and avoid borders, text, logos, or misleading overlays.
- For local listings, include scale and pickup context for large items.
- Make the first image the cleanest full-item hero shot.

## Output Contract

Always produce practical artifacts the user can copy, paste, configure, or hand to a contractor.

- Platform-specific shot list.
- First-photo recommendation.
- Flaw disclosure photo plan.
- Staging and lighting checklist.
- Retake instructions if photos are inadequate.

## Quality Checklist

Before finalizing, verify:

- Photos reduce buyer uncertainty.
- Flaws are shown clearly, not hidden.
- The photo set answers condition, size, completeness, and authenticity questions.

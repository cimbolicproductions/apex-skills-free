# Marketplace Negotiation Scripts

## When to Use This Skill

- The user needs replies to buyers.
- A buyer lowballs, asks if available, wants delivery, wants a hold, or missed pickup.
- The seller wants to close without wasting time.

## When Not to Use This Skill

- A buyer appears to be running a scam; use marketplace-scam-safety first.
- The issue is an eBay dispute requiring platform policy review.

## Intake Questions

Ask only for missing information that changes the output. If enough context exists, proceed and state assumptions.

- Platform, item, list price, floor price, buyer message, pickup/delivery terms.
- Is the seller willing to negotiate, hold, deliver, or bundle?
- What is the desired tone: firm, friendly, fast-sale, or premium?

## Operating Workflow

- Pre-qualify availability replies with pickup time and payment method.
- Answer lowballs with a firm counter near target price or invite pickup today at a small discount.
- Use first buyer with confirmed time and payment as priority. Avoid indefinite holds.
- For delivery, charge a clear fee and define radius, curbside/inside, and timing.
- For no-shows, move immediately to backup buyers.
- Keep messages short and avoid emotional negotiation.

## Output Contract

Always produce practical artifacts the user can copy, paste, configure, or hand to a contractor.

- Reply scripts for common buyer messages.
- Lowball counteroffer ladder.
- Pickup scheduling template.
- Hold and no-show policy.
- Delivery fee language.

## Quality Checklist

Before finalizing, verify:

- Scripts are concise enough for mobile copy/paste.
- The seller's floor price is protected.
- Pickup details reduce back-and-forth.

# B2B Property Manager Outreach

## When to Use This Skill

- The user wants recurring B2B local service clients.
- The target buyers are property managers, landlords, STR hosts, HOAs, commercial accounts, or facility managers.
- The user needs cold email, call scripts, objection handling, or lead sourcing.

## When Not to Use This Skill

- The customer is a one-off residential consumer lead.
- The user wants app/SaaS sales outreach instead of local services.

## Intake Questions

Ask only for missing information that changes the output. If enough context exists, proceed and state assumptions.

- Service offered, city, ideal property type, capacity, proof, guarantee, and service radius.
- Who is the buyer and what recurring pain do they have?
- What offer is low-risk: audit, emergency backup, pilot, annual plan, or volume pricing?

## Operating Workflow

- Build a lead list from Google Maps, Chamber, BOMA, REIA, local investor groups, and city-specific STR groups.
- Use a 4-touch sequence over 14 days: intro, value drop, proof, breakup.
- Keep emails short, local, specific, and under 100 words when cold.
- Lead with reliability, response time, documentation, tenant/guest satisfaction, and reduced vendor headache.
- Prepare objections: already have someone, send info, too expensive, not now, need approval.
- Track each account in CRM as target, contacted, replied, meeting, proposal, won, lost, nurture.

## Output Contract

Always produce practical artifacts the user can copy, paste, configure, or hand to a contractor.

- Lead sourcing plan.
- 4-email sequence.
- Call opener and voicemail.
- Objection response bank.
- CRM pipeline stages.

## Quality Checklist

Before finalizing, verify:

- Each message contains a local or role-specific hook.
- The ask is a low-friction 10-minute call or pilot, not a huge commitment.
- Direct Airbnb platform outreach is avoided when it would violate platform norms or terms.

# Used Appliance Inspection Guide

## When to Use This Skill

- The user is buying, selling, refurbishing, or renting an appliance.
- An appliance needs condition grading before pricing or listing.
- The user wants a pickup/delivery inspection checklist.

## When Not to Use This Skill

- The appliance has an active safety recall or electrical/gas hazard; stop and verify first.
- The user needs deep troubleshooting of a symptom; use appliance-repair-triage.

## Intake Questions

Ask only for missing information that changes the output. If enough context exists, proceed and state assumptions.

- Appliance type, brand, model, serial, age if known, symptoms, photos, and whether power/water/gas testing is possible.
- Goal: buy, sell as-is, refurbish, rent, or warranty.
- Known defects, missing parts, cosmetic issues, and smell/noise concerns.

## Operating Workflow

- Record model and serial before moving the unit.
- Check recall status and approximate age when identifiers are available.
- Inspect exterior, tub/drum/cavity, seals, hoses, cords, vents, controls, leveling feet, and signs of leaks or pests.
- Run safe functional tests appropriate to appliance type.
- Classify condition as parts-only, as-is working, tested used, refurbished, or rental-ready.
- Estimate parts, labor, cleaning, delivery, warranty risk, and resale/rental value.

## Output Contract

Always produce practical artifacts the user can copy, paste, configure, or hand to a contractor.

- Inspection checklist by appliance type.
- Condition grade.
- Pass/fail tests.
- Repair/cleaning punch list.
- Buy/list/rent recommendation.

## Quality Checklist

Before finalizing, verify:

- Gas, electrical, and water safety risks are flagged.
- The recommendation accounts for repair cost and warranty risk.
- Unknowns are listed instead of assumed.

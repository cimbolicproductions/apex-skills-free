# Direct-Response Copywriter

Writes direct-response copy for landing pages, emails, ads and social posts using AIDA, PAS or BAB, with benefits over features, plain language, three ranked headlines and one clear call to action. Use when the user asks for sales copy, an ad, an email or a page that needs to convert better.

## Install and use

Add the Apex Skills Free marketplace in Claude's Customize > Plugins, then select this plugin. In Claude Code, use:

```text
/plugin marketplace add https://github.com/cimbolicproductions/apex-skills-free.git
/plugin install apex-copywriting-mastery@apex-skills-free
```

Ask for the workflow in plain language or select its skill. Read the linked instructions and reference files to understand the procedure and required inputs.

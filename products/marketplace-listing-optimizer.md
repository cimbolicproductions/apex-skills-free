# Marketplace Listing Optimizer

## When to Use This Skill

- The user wants to sell an item online or locally.
- The listing needs title, description, tags, condition, photos, pricing, or pickup terms.
- A listing is getting views but not messages, or messages but not sales.

## When Not to Use This Skill

- The item is prohibited, recalled, counterfeit, unsafe, or illegal to sell.
- The user needs appliance diagnosis before listing; use appliance-repair-triage or appliance-inspection-guide.

## Intake Questions

Ask only for missing information that changes the output. If enough context exists, proceed and state assumptions.

- Platform, item type, brand, model, size, age, condition, flaws, accessories, location, and desired speed of sale.
- What photos exist and what is missing?
- Will it be shipped, delivered, or local pickup only?

## Operating Workflow

- Choose platform based on item size, buyer intent, shipping fit, and local demand.
- Write searchable title: brand, product type, model, key attribute, size/color, condition.
- Use all important item specifics for eBay so filtered searches can find it.
- Write a scannable description with condition, measurements, what's included, pickup terms, and flaws.
- Disclose damage clearly to reduce returns and wasted meetups.
- Include pickup or delivery terms, payment terms, and first-come/hold policy.
- Create relist plan if no traction after 7, 14, or 30 days depending on platform.

## Output Contract

Always produce practical artifacts the user can copy, paste, configure, or hand to a contractor.

- Platform-specific title variants.
- Optimized description.
- Photo checklist.
- Condition disclosure.
- Pickup/payment terms.
- Relisting and price-drop plan.

## Quality Checklist

Before finalizing, verify:

- The first photo and first 60 title characters carry the main search intent.
- No keyword spam, emojis, or misleading claims.
- Buyer questions are pre-answered in the listing.

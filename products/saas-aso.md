# App Store Optimization

## When to Use This Skill

- The user wants more app downloads or better store conversion.
- The user needs App Store title, subtitle, keyword field, screenshots, preview video, or Google Play description.
- The user asks for ASO tests, metadata updates, or custom product pages.

## When Not to Use This Skill

- The app is not ready for store listing or has no visual assets.
- The user needs general SaaS landing page copy.

## Intake Questions

Ask only for missing information that changes the output. If enough context exists, proceed and state assumptions.

- Which store: iOS, Google Play, or both?
- What are the core keywords, competitors, and top user benefits?
- What screenshots or app flows are available?

## Operating Workflow

- Respect store-specific indexed fields: iOS title, subtitle, keyword field; Google title, short description, long description.
- Do not stuff iOS description for SEO because it is conversion copy, not the main keyword field.
- Use screenshot storytelling: first slide shows strongest outcome, next slides explain use cases and proof.
- Keep preview videos understandable without sound and hook in the first 5 seconds.
- Plan A/B tests one element at a time: icon, first screenshot, subtitle, short description, or video.
- Create update cadence: iOS roughly monthly, Android every 6 to 8 weeks when there is enough data.

## Output Contract

Always produce practical artifacts the user can copy, paste, configure, or hand to a contractor.

- Metadata drafts for each store.
- Keyword map.
- Screenshot storyboard.
- Preview video brief.
- A/B test plan.

## Quality Checklist

Before finalizing, verify:

- Character limits are respected.
- Screenshots sell benefits, not just UI labels.
- Keyword use remains human-readable.

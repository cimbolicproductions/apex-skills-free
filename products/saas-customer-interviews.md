# SaaS Customer Interviews

## When to Use This Skill

- The user asks what to ask potential customers.
- The user has interview transcripts, notes, or call summaries to analyze.
- The user needs ICP, JTBD, pains, buying triggers, or objections.

## When Not to Use This Skill

- The user wants sales demo scripts after the product is already positioned.
- The user only needs a survey for existing active users; use PMF engine if PMF is the goal.

## Intake Questions

Ask only for missing information that changes the output. If enough context exists, proceed and state assumptions.

- Who are you interviewing and how did you recruit them?
- What decision will the interviews inform?
- Do you need discovery, pricing, usability, churn, or win/loss learning?

## Operating Workflow

- Start with the customer's world: role, current workflow, trigger event, current workaround.
- Ask for concrete past behavior: last time, tools used, time spent, money lost, who approved.
- Avoid leading questions such as would you use this or would you pay.
- Capture exact phrases, pains, objections, and alternative solutions.
- Cluster interviews by shared problem intensity and buying ability.
- Translate patterns into ICP, positioning, roadmap, and validation next steps.

## Output Contract

Always produce practical artifacts the user can copy, paste, configure, or hand to a contractor.

- Interview script.
- Forbidden question replacements.
- Insight table.
- ICP and JTBD summary.
- Recommended product or sales actions.

## Quality Checklist

Before finalizing, verify:

- Every insight is traceable to something a user actually said or did.
- Do not overgeneralize from fewer than 5 interviews.
- Separate problem evidence from solution preference.
